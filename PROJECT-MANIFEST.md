# Project Manifest

Created by School of AI and School of QC.

This release contains a reusable Python package, three-workflow Streamlit application,
command-line interface, saved-model CSV forecaster, quickstart notebook, frozen experiment
configuration, deterministic data generator, automated test suite, Python 3.11/3.12 GitHub
Actions workflow, MIT license, citation metadata, governance templates, curated evidence, and
focused technical guides.

The default run creates 34 auditable files inside a timestamped `artifacts` directory. They
include the generated series and causal frame, split assignments, model files, exact quantum
dynamics, Hamiltonian coefficients, fitted preprocessing, one-step forecasts, recursive rollout,
memory and finite-shot diagnostics, environment metadata, eleven plots, and a Markdown report.

Generated series, timestamped runs, caches, virtual environments, and build outputs are excluded
from version control. The compact `examples/reference-run` bundle and selected `docs/assets`
plots are intentionally tracked so the README's numerical claims remain inspectable without
committing large fitted models or feature matrices.
