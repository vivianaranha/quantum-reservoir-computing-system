# Roadmap

Created by School of AI and School of QC.

- Add repeated-seed estimates with confidence intervals.
- Compare alternative Hamiltonians, input encodings, observable sets, and reset channels.
- Add readout retraining under finite-shot features and joint measurement-group accounting.
- Support density-matrix noise channels and optional hardware-backend adapters.
- Add rolling-origin evaluation across multiple Mackey–Glass regimes and real public datasets.
- Add uncertainty bands, forecast calibration, and stability-aware readout selection.
- Benchmark sparse simulation and tensor-network approximations beyond five qubits.
- Add experiment tracking without introducing a required cloud service.
