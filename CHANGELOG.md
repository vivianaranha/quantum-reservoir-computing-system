# Changelog

Created by School of AI and School of QC.

## 1.0.0 — 2026-09-22

- Added an exact density-matrix quantum reservoir with fixed seeded XX and local-Z dynamics.
- Added mixed-state input injection, virtual nodes, and single- and two-qubit Z observables.
- Added a trainable ridge readout with validation-selected regularization.
- Added a size-matched echo-state network, autoregressive ridge, random forest, and persistence.
- Added chronological train/validation/test evaluation, recursive rollout, delayed-input memory,
  and finite-shot sensitivity diagnostics.
- Added a CLI, three-workflow Streamlit app, saved-run CSV inference, and quickstart notebook.
- Added independent Qiskit parity tests, reproducible artifacts, curated reference evidence,
  documentation, CI, and GitHub contribution templates.
